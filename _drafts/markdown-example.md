## Start with a story

Use ordinary Markdown to explain an idea, with *emphasis* where it helps.

- Describe the audience's problem.
- Show how a comic can explain it.
- Give the reader a useful next step.

Visit [ComicFire](https://comicfire.com/) to explore the product.

### Code and examples

```text
Problem → Story → Clear next step
```

Keep any article images in this repository and reference them with a relative URL.
